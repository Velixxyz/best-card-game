Ember Pact is a turn-based card duel that plays offline in a desktop browser: spend mana, chain the four elements, and burn the Ashen Warden's ember to zero before yours fades.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and click Start the Duel.
